## AI 辅助招聘平台

面向招聘专员、用人经理和招聘经理，串联从岗位需求到入职登记的协作流程。

- **AI 辅助分析**：按岗位条件对照简历，展示结论与原文引用，支持人工核对和修正。
- **多角色协作**：按角色划分操作权限，提供招聘进度看板、站内提醒与操作留痕。
- **演示方式**：支持无 API Key 的本地演示模式，可体验主要业务流程；接入模型后可进行真实 AI 分析。

**技术栈**：JavaScript、Node.js、SQLite、服务端页面渲染、大模型 API 集成。

下载并解压后，按项目内 README 启动；Windows 可使用 `启动演示.bat`。详细功能、测试说明与当前限制见项目内文档。

## 天气应用 · Web 演示

通过城市选择与天气信息卡片，展示第三方天气接口集成和页面交互。

- **城市切换**：动态加载城市列表，点击城市查询天气。
- **数据展示**：接入高德天气 API，展示城市、温度、天气描述与对应图片。
- **界面交互**：根据天气切换卡片背景，配合页面动画呈现查询结果。

**技术栈**：HTML、CSS、JavaScript、jQuery、第三方天气 API。

当前仓库提供 Web 演示代码。鸿蒙版本的源码、运行环境与演示录屏可另行补充。
